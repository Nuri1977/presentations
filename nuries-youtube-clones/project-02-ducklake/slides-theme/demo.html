Project 2 · Lesson 1.4
Three ways to store analytics data

Warehouse, lake, lakehouse

Warehouse
One system owns everything
Fast and safe, but the data lives in its format.
Data lake
Just files
Cheap and open, but no transactions and no schema.
Lakehouse
Open files, table rules
Transactions, schema and history on top of files.
  • ACID changes
  • Time travel
  • Not a server you must run
