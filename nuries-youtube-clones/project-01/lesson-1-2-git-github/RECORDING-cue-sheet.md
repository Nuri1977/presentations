# Git and GitHub — recording cue sheet

For a human retake of the app scenes (the automated recording follows the same steps). App: Rosetta DBT Studio 1.7.6, dark theme, window 1920x1080.

## Before you start

- Recorder browser profile signed in to GitHub as Nuri1977 (browser-login.cjs); the scene starts on the public rosettadb/dbt-studio page so no personal dashboard is shown.
- Rehearsal run: the repository is nyc-taxi-dbt-rehearsal and Private. The final run creates nyc-taxi-dbt, Public, with the same steps.

## s03 · Create the repository

| Listen for | Do this |
|---|---|
| "Let's create the repository. On GitHub, signed in,…" | In the browser, open https://github.com/rosettadb/dbt-studio<br>Click **+ Create new**<br>Click **New repository** |
| "Give it a name. This is a rehearsal…" | Click **Repository name** and type `nyc-taxi-dbt-rehearsal`<br>Wait 1.5 s<br>Click **Choose visibility**<br>Click **Private** |
| "Leave everything else empty: no README, no gitignore,…" | Point at **Add README**<br>Point at **No .gitignore**<br>Point at **No license**<br>Click **Create repository** |
| "The repository is ready, and empty. GitHub shows…" | Point at **Clone URL**<br>Click **Copy URL** |
