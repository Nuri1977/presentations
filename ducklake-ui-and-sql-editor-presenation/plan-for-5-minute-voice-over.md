## 0:30-0:50

Meet Rosetta DBT studio: a desktop workspace for modern data teams.

Manage DuckLake lakehouses, connect to cloud storage, explore metadata, query data, and build notebook workflows without jumping between tools.

Under the hood, Rosetta DBT studio uses the DuckDB Node.js API to connect to DuckDB and power DuckLake workflows through DuckDB's DuckLake extension.

## 0:50-1:25

Data work often gets split across database clients, cloud consoles, SQL tools, notebooks, and file explorers.

Rosetta DBT studio brings those workflows together, so teams can move from connection setup to analysis and lakehouse operations in one focused interface.

## 1:25-2:05

Start by connecting the systems your team already uses.

Rosetta DBT studio supports database connections and cloud object storage, including S3-compatible storage, Azure Blob, and Google Cloud Storage.

Those saved cloud connections can be reused when creating new DuckLake instances or importing existing DuckLakes, keeping setup clean and secure.

## 2:05-2:45

The DuckLake setup flow guides you through the essentials: instance details, catalog configuration, storage location, runtime options, and final review.

You can create a new DuckLake or import an existing one by connecting the metadata catalog and data storage, matching the way DuckLake is designed to work.

## 2:45-3:25

Once the instance is running, Rosetta DBT studio becomes a visual control center for DuckLake.

Browse tables and views, inspect schemas, review statistics, see Parquet data files, examine partitions, and follow snapshot history.

It gives teams a practical way to understand what is inside the lakehouse, not just query it.

## 3:25-3:55

The DuckLake UI is built for real operations: schema evolution, row updates, deletes, and importing data from cloud storage or URLs.

It helps turn lakehouse management into a guided workflow instead of a set of disconnected commands.

## 3:55-4:35

DuckLake also works directly inside the SQL Editor.

Select a DuckLake instance, browse schemas, get Monaco-powered autocomplete for tables and columns, run queries, page through large results, and export full datasets to CSV, JSON, or Parquet.

## 4:35-5:10

For deeper analysis, SQL Notebooks provide a cell-based workflow with SQL and Markdown.

Create reusable notebooks, run cells against DuckLake or database connections, keep results paginated for large tables, and document the analysis as you go.

## 5:10-5:30

Rosetta DBT studio brings DuckLake management, SQL exploration, notebooks, cloud storage, and AI-ready analytics into one desktop experience.
