What is DuckLake

Open Lakehouse on Your Storage

DuckLake stores your data as Parquet files in cloud object storage — S3, Azure Blob, or Google Cloud Storage — with a SQL catalog on top. No proprietary formats, no vendor lock-in. Just open data you actually own.

Visual Control

Browse Tables, Manage Schema

Browse every table and view, inspect columns and data types, see Parquet files and partitions, update rows, and track the full snapshot history — all without writing a single command.

SQL Editor

Query DuckLake Directly

Connect the SQL Editor to any DuckLake instance. Schema browser on the side, autocomplete as you type, large result sets paginated automatically. Export your results to CSV, JSON, or Parquet in one click.

DuckLake, Finally Simple

Create instances, manage tables, query data, track history — all in one desktop app. No CLI required.
