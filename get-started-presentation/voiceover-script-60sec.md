# 60-Second Voice-Over Script: Rosetta DBT Studio — Get Started

## Overview

**Total Duration**: ~60 seconds  
**Target Word Count**: ~130–150 words (≈130 words/min at a relaxed, clear pace)  
**Tone**: Energetic, confident, practical, welcoming  
**Voice Direction**: Upbeat and clear. Emphasise the speed and simplicity. Pause briefly between sections.

## Full Script

---

### [0:00–0:08] Hook

*(Quick zoom on logo, then fast cuts through project list, form, and editor)*

"**From zero to running in 60 seconds.**

Meet **Rosetta DBT Studio** — the fastest way to get your dbt project up and running.

Create a new project, clone from GitHub, or import a folder. Pick your database. Start building."

---

### [0:08–0:15] Project List

*(Show project list screen)*

"When you open Rosetta, you see all your dbt projects in one place.

Click **New Project** to start fresh, or **Clone from Git** to bring in an existing repository."

---

### [0:15–0:25] New Project Form

*(Show new project form with database selection)*

"Give your project a name, pick a location, and choose your database.

**DuckDB** is pre-configured and ready to go. Or pick from **PostgreSQL, Snowflake, BigQuery, Redshift, Databricks** — and 20+ more."

---

### [0:25–0:35] Database Selection

*(Show database dropdown with icons)*

"Each connection type has smart defaults. Fill in your credentials, test the connection, and you're done.

All credentials are stored securely in your system keychain."

---

### [0:35–0:45] Clone from GitHub

*(Show clone modal)*

"Or skip the setup entirely. **Clone from GitHub.**

Paste a repository URL, select your branch, configure your database connection, and you're ready to work."

---

### [0:45–0:55] DBT Editor

*(Show full dbt editor workspace)*

"Your dbt workspace is ready.

File explorer, SQL editor, integrated terminal. Write models, run tests, and see results in real time."

---

### [0:55–1:00] Closing

*(Fast montage, settle on CTA screen)*

"**From zero to running in 60 seconds.**

Download **Rosetta DBT Studio** for macOS, Windows, or Linux today. Star us on GitHub."

---

## Delivery Notes

- **Emphasise** the speed: "60 seconds," "in seconds," "ready to go."
- **Pause** for 0.3–0.5 seconds between major sections.
- **Pick up pace** during the fast montage opening and closing.
- **Slow down slightly** when listing database options: "PostgreSQL, Snowflake, BigQuery, Redshift, Databricks."
- **End warmly** on "Star us on GitHub."
