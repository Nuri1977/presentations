1.7.0 Notebooks

Python notebooks

Save a SQL result as df, then work with it as a pandas DataFrame in the next Python cell.

1.7.0 Notebooks · How it works

Query in SQL, analyze in Python

Three cell types share one notebook, connected to the database you select.

01 · SQL

Query the connection

A SQL cell runs against the selected connection. Use Result as to give the result a name, like df.

02 · PYTHON

Use the DataFrame

Python cells see the named result as a pandas DataFrame. display(df) renders a filterable, paged table with column types.

03 · TEXT

Explain the work

Markdown cells add headings and notes so the analysis reads as a story.

Run cells from top to bottom: a Python cell can only use df after its SQL cell has run. The toolbar shows the Python version and kernel status.

1.7.0 Quality

Smoother everyday work

Fixes that remove interruptions from the SQL editor and project switching.

SQL Editor

No more crash on error objects

When a database returns an error object instead of a message, the editor shows the error and keeps running.

Schema

Quiet when a server is down

Unreachable servers no longer trigger repeated “Failed to fetch schema” alerts.

Projects

Straight into your project

Picking a project from its card or the top-bar dropdown now takes you directly to it.

1.7.1 Schema tree

Right-click any table

  • Insert or copy the name, qualified name or column list.
  • Generate SQL: SELECT *, SELECT columns, COUNT(*) or an INSERT template.
  • Preview data, rename the table or refresh the schema.
  • Drag & drop items from the tree into your editor.
