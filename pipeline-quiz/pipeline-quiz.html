The big idea

A recipe your computer can follow

A pipeline is a saved list of steps. Rosetta DBT Studio reads the list from top to bottom and asks the right helper to do each step.

1

You make the recipe

Choose little building blocks, join them together, and give each one a clear job.

2

Studio saves the map

Your pipeline becomes a YAML file inside rosetta/pipelines/.

3

A runner follows it

Run it on your own computer, or use Cloud when the project is ready in Git.

Four tiny chapters

Meet the pieces

🧩

Steps are building blocks

Each step has a name and a tool. A dbt step can build models. A command step can run an approved command. Rosetta, Terraform, S3, and Kinetica helpers can do their own special jobs. One small step should have one clear purpose.

Simple name = easier to understand later
🗺️

Visual mode is your map

Drag blocks onto the canvas and connect them with arrows. The arrows show what comes next. You can undo and redo while editing. Before saving, Studio checks for missing names, missing information, empty maps, and circles that never end.

A circle is called a cycle—and Studio says “not yet!”
📝

YAML mode is the written recipe

The same pipeline can be read as text. YAML is careful about spaces, names, jobs, and steps. Visual mode and YAML mode are two views of the same saved file, not two different pipelines.

New pipelines live in rosetta/pipelines/
🚦

Local and Cloud are two roads

Local runs with the Runner on your computer and does not need a Git commit. Cloud runs the version from the remote Git branch, so the selected pipeline must be committed and pushed. Local changes do not secretly travel to Cloud.

Cloud reads the remote copy, not your unsaved desk copy

3 · SaveThe recipe is written to its pipeline YAML file.
4 · RunChoose Local Runner or the remote Cloud road.
5 · WatchRead step status and logs to learn what happened.
✓

Save before the train leaves

If visual changes are waiting, Studio asks whether to save, discard, or cancel before switching views or running.

G

Git matters for Cloud

The Cloud road needs a repository, remote URL, remote branch, and a pipeline file without uncommitted or unpushed changes.

↺

Old folders still open

Studio can read older pipeline files under .rosetta, but newly created files use rosetta/pipelines.

AI

The Project Agent can help write

It can list, read, generate, and safely update saved pipeline files—but it does not run, commit, or push them for you.
