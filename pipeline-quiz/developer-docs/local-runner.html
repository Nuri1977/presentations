Chapter 04

Local Runner

Local execution uses the exact working-tree pipeline and a managed Runner installation. It is independent from Flowfile and Rosetta Cloud.

runner:*ProcessAdapterRunnerProvider

Execution flow

User runs a selected .yml or .yaml pipeline
RunnerProvider sends project and pipeline identity
runner.ipcHandlers resolves trusted settings and validates the target
ProcessAdapter starts the managed Runner with a child-only environment
runner:* events stream ordered output into Runner Logs

Responsibilities

RunnerService

Discovers releases, validates versions, stages installation, manages the plugin bundle, and constrains cleanup to Runner-owned storage.

RunnerProvider

Owns renderer run state and subscriptions. The visible Run action becomes Stop for the actively running file.

IPC handler

Resolves the executable from main-process Settings rather than accepting an arbitrary renderer path.

ProcessAdapter

Owns process finalization. Output and error ordering is preserved, and application quit waits for the Runner to stop.

Channels

runner:run       runner:status     runner:stop
runner:output    runner:error      runner:started
runner:exit      runner:done
Local means local: Git status is not a precondition. The Runner reads the selected working-tree pipeline, including committed or uncommitted local content.
