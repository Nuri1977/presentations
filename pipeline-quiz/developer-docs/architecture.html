Chapter 01

Pipeline architecture

The pipeline feature is not a single service. It is a collaboration between a renderer workspace, typed Electron IPC, trusted main-process services, and two independent execution backends.

dev · a229dcf9ElectronReact + React Flow

Ownership model

Renderer

Owns the virtual editor tab, live draft, Visual/YAML mode, validation presentation, confirmation dialogs, and log views. It sends project and pipeline identities across IPC.

Main process

Owns project filesystem access, Runner binary resolution, child processes, Cloud requests, secure values, and persisted action mappings.

File discovery flow

Project UI requests project:listPipelines
projects.ipcHandlers.ts delegates without business logic
ProjectsService recursively scans canonical and legacy roots
Renderer receives bounded PipelineFile identities
Opening a recognized file creates a virtual Pipeline Editor tab
