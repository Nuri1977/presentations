# 3-Minute YouTube Video Plan: Rosetta DBT studio — The AI Agent

## Goal
Create a fast-paced, high-impact 3-minute video showing the AI Agent acting as an autonomous dbt engineer. Focus on speed, security, and extensibility.

## Core Message
The AI Agent is not a chatbot—it's a tool-calculating engine that reads your project, writes SQL, and runs dbt commands. It's safe (confirmation-gated), flexible (Multi-provider/Local), and extensible (Skills/MCP).

---

## Video Structure

### 0:00–0:30 — Hook: Beyond the Chatbox
**Visuals**: Fast montage showing the Agent executing tasks: "Writing model...", "Compiling...", "Formatting...".
**VO**: "Stop copy-pasting. Meet the AI Agent in Rosetta DBT studio—your autonomous partner for the full dbt lifecycle."

### 0:30–1:15 — Intelligent Action: Tools & Auto-Open
**Visuals**: Show the agent's interleaved "thought process" (tool calls in chat). As it writes a model, show the file instantly opening in a Monaco tab.
**VO**: "Powered by the Vercel AI SDK, the Agent uses native tools to explore your project and write code. It doesn't just suggest—it implements, auto-opening files in your editor for immediate review."

### 1:15–1:45 — Security: Human-in-the-Loop
**Visuals**: Highlighting the Terminal Confirmation banner for a `dbt run` command.
**VO**: "Autonomy with zero risk. The Agent can never execute terminal commands or overwrite changes without your explicit permission via the Terminal Confirmation Gate."

### 1:45–2:30 — Extensibility: Skills & MCP
**Visuals**: Quick tour of the Skills UI and MCP settings. Import a "Style Guide" skill.
**VO**: "Customize your assistant. Teach it your standards with the Skills library or connect it to external tools via the Model Context Protocol. It's your logic, powered by AI."

### 2:30–3:00 — Closing: Modern Engineering
**Visuals**: Final shot of the dashboard. CTA: Download and GitHub Star.
**VO**: "Join the future of analytics engineering. Download Rosetta DBT studio today."
