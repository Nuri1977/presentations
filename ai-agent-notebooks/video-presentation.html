Ask Mode

Ask About Any Cell

Ask the Agent a question about any cell — the SQL, the result, the model it references. It reads the surrounding context and answers from what's actually in your notebook.

"Why is revenue dropping in October?" — "What does this JOIN do?" — "Is this aggregation correct?" Read-only. Safe. Grounded in your data.

Generate

Describe It. Get a Cell.

Tell the Agent what you need in plain language. It writes a new SQL cell, wires up the correct ref() references for your dbt models, and inserts it directly into your notebook.

The Agent knows your project schema and follows the grain of what you're already building. No copy-pasting from a chat window.

Execute & Iterate

Run. Read. Keep Going.

The Agent doesn't stop at writing SQL. It executes the cell, reads the result, and continues — refining the query if the data looks off, or writing the next cell automatically.

Multi-cell workflows run end to end. The Agent holds the full notebook context — every result, every step — as it works.

Safety First

You Approve Every Write Cell

Read queries execute freely. Any cell that modifies data — INSERT, UPDATE, DELETE, or DDL — pauses and shows you exactly what it wants to run. You click Allow or Deny. It never writes without your permission.
