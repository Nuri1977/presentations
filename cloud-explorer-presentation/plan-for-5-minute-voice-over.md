# 5-Minute Voice-Over Script: Rosetta DBT studio — Cloud Explorer

## Overview

**Total Duration**: ~5 minutes  
**Target Word Count**: ~650–700 words (≈130 words/min at a relaxed, clear pace)  
**Tone**: Professional, confident, practical, accessible  
**Voice Direction**: Calm and measured. Emphasise key technical terms clearly. Pause briefly between sections.

## Full Script

---

### [0:00–0:20] Hook

*(Slow zoom in on logo, then quick cuts to dashboard and preview screens)*

"Meet the **Cloud Explorer** in **Rosetta DBT studio** — one desktop workspace to connect, browse, manage, and preview data from every major cloud storage provider.

No extra tools. No context switching."

---

### [0:20–0:50] The Problem

*(Animate seven provider icons converging into the Rosetta DBT studio workspace)*

"Data teams juggle multiple cloud storage providers — each with its own console, its own access patterns, and its own way of browsing files.

Rosetta DBT studio's Cloud Explorer solves this by connecting all seven providers — **S3, Azure Blob, GCS, MinIO, Cloudflare R2, Backblaze B2, and rustfs** — into one unified interface."

---

### [0:50–1:25] Connections

*(Show new connection form, highlight provider dropdown and credential fields)*

"Adding a cloud connection is straightforward. Select the provider, fill in the credentials, and **test the connection** before saving.

All sensitive credentials are stored securely in the **system keychain** — never in plain text.

Connections are reusable across the entire workspace, so you configure once and use everywhere."

---

### [1:25–2:00] Browsing Buckets and Files

*(Show bucket list card view, then breadcrumb file navigation)*

"Once connected, Cloud Explorer lets you navigate buckets and files just like a desktop file browser.

Toggle between **card and list view**, use **breadcrumbs** to go deeper into folder hierarchies, and search within large directories.

File types are automatically detected and shown with distinct icons."

---

### [2:00–2:25] File Management

*(Show create bucket, upload files, rename and delete screens)*

"Cloud Explorer is **not read-only**.

Create new buckets, upload files, create folders, rename objects, and delete files — all from the same interface, across any connected provider.

No cloud console required."

---

### [2:25–2:50] Recent Items

*(Show recent items screen with file and folder filter)*

"The **Recent Items** view tracks the last fifty locations you accessed.

Filter between files and directories for quick lookup, and jump back to any recent location with a single click."

---

### [2:50–3:30] DuckDB Preview

*(Show multi-format badge screen, then paginated data table with rows-per-page selector)*

"The real power of Cloud Explorer is **DuckDB-powered data preview**.

Click any supported file and Rosetta DBT studio queries it directly in the cloud using DuckDB. **CSV, Parquet, JSON, JSONL, AVRO, and Excel** files are all supported.

True **server-side pagination** means only the current page of rows is loaded — so you can preview files with **hundreds of millions of rows** without exhausting memory."

---

### [3:30–4:00] Schema, Statistics, and Filter Builder

*(Show schema tab, statistics tab, filter form, filtered result with chip)*

"The full-screen modal adds a **Schema tab** to inspect column names, types, and nullability — straight from file metadata for Parquet.

The **Statistics tab** computes null count, distinct values, min, max, and mean per column using a ten-thousand-row DuckDB sample.

And the **Filter Builder** lets you construct WHERE clause conditions without writing SQL — pick a column, choose an operator, type a value, and apply."

---

### [4:00–4:40] Closing

*(Fast montage, then settle on CTA screen with logo and download buttons)*

"Rosetta DBT studio's Cloud Explorer brings **seven cloud providers**, DuckDB-powered file previews, server-side pagination, visual filter builder, schema inspection, and column statistics into one cohesive desktop workspace.

Download **Rosetta DBT studio** for macOS, Windows, or Linux today, and **star us on GitHub**.

Let's build better data workflows together."

---

## Delivery Notes

- **Pause** for 0.5–1 second between each major section heading.
- **Emphasise** provider names (S3, MinIO, R2) with slightly more weight.
- **Slow down** slightly when listing: "CSV, Parquet, JSON, JSONL, AVRO, and Excel".
- **Pick up pace** during the fast montage closing section (4:00–4:40).
- **End warmly** on "Let's build better data workflows together."
