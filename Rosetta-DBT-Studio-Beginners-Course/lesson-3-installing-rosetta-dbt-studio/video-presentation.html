Setup

Installing Rosetta DBT Studio

Windows first, then Mac. Skip ahead to whichever one you are on.

Nothing to set up beforehand, and no terminal to open.

Windows and Mac Python included dbt installed for you
Windows, Download

One installer

rosettadb.io, Download Now, Choose your build, then Download for Windows.

Windows, Install

Run it and wait

Nothing to choose, no options to set. It brings its own Python, so nothing else to install.

First Launch

It sets itself up

Leave every adapter ticked and click Install. It installs dbt and every adapter.

Setup Complete

Two confirmations

Python installed, dbt installed. Click Finish and the app opens.

Quick Tour

A tour of this screen

Where your projects live, how to start one, and where connections are kept.

Part Two

On a Mac?

Same steps, a few small differences.

Mac, Download

Two builds

Mac ARM64 for Apple Silicon, or Mac Intel. Pick the one that matches your Mac.

Mac, Install

Drag it to Applications

Open the file, drag Rosetta DBT Studio across. That is the whole install.

First Launch

It builds itself

Rosetta is downloading and Python is being unpacked, so the setup has what it needs.

Setup Wizard

Seven boxes, all ticked

dbt core plus six database adapters, so it works with whatever you connect to later.

Setup Complete

Two confirmations

Python installed, dbt installed. Click Finish and the app opens.
