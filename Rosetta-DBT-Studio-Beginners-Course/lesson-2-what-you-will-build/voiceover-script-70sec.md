# What you'll build - Voiceover

Slide 1 - Hook

By the end of this course you will have a working dbt project. Your own models, a lineage graph, and AI writing your SQL.

Let's look at how that comes together.

Slide 2 - A real project

Raw data goes in, and these are your models. Clean tables, built from SQL that you wrote.

It is the same structure that real data teams use every day.

Slide 3 - The lineage graph

Rosetta draws the shape of your project for you. Every model, and what it depends on.

So when you change one thing, you can see exactly what it affects.

Slide 4 - AI writes the SQL

You will also have AI built into the app. Ask a question in plain English, and it writes the query for you.

Slide 5 - The path

We will get there one step at a time. Install the app. Create a project. Understand the files. Generate your models, and run them.

After that, the SQL editor, notebooks, your own database, and the cloud.

Next up, installing Rosetta DBT Studio.
