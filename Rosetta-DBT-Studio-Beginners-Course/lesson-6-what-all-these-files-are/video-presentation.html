Your First Project

What all these files are

Mostly empty folders, and that is how a dbt project starts.

Here is what each one is for, and which ones you will actually touch.

Seven folders Three files One that matters
The Project File

It is called dbt_project.yml

Every folder path dbt uses is set in here. Rename a folder and this file has to agree.

The Connection

Four lines, one database

profiles.yml: type duckdb, schema main, threads 4. That is the entire connection.

Models

The file name becomes the table

One .sql file is one model. dbt works out the order they build in, so you never write it down.

Seeds

Small files that rarely change

Country codes, category mappings, a lookup list. Raw data belongs in the database, not in your repo.

Optional Folders

Four you can ignore for now

They ship with every dbt project. A first project usually uses none of them.

The Rosetta Folder

Four tables, 100 rows each

students, courses, enrollments and grades, in a 1.3 MB file called university_sample.duckdb.

Not There Yet

Two absences, no action

You create neither. target arrives on the first dbt run.
