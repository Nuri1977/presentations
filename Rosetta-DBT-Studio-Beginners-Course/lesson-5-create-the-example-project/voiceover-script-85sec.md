# Create the example project - Voiceover

Slide 1 - Intro

Time to get a real project on screen.

No credentials, no cloud account, and no database to set up. Rosetta DBT Studio ships an example that you can clone in one click.

Slide 2 - Get Started

On the projects screen, click Get Started.

Slide 3 - What you get

It tells you what you are about to clone. The important part is the DuckDB database, with sample data already in it.

That is why this needs no credentials. The database is just a file, sitting on your machine.

Slide 4 - Create it

This clones the getting started repository from GitHub. You could clone that yourself from the same address, but this saves you the trip.

Click Create Example Project.

Slide 5 - It opens

And the project opens.

There is the database, one file in the rosetta folder, plus everything else dbt needs to run. What you do not have yet is models. The folder is there, with nothing written to it yet, which is exactly how a new project should start.

Slide 6 - Closing

That is your first project, in about a minute.
