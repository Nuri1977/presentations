The Basics

What is dbt?

If you work with data, you have a folder of SQL files. And in your head, the order you are supposed to run them in.

That list in your head is the problem dbt solves. Here is the whole idea, start to finish.

SQL you already write Built in the right order No new language
The Core Idea

A model is just a SELECT

You write the query. dbt creates the table. There is no new language to learn - it is the SQL you already write.

Running It

Run it, and it builds

One command. Every model you wrote becomes a table.

Dependencies

dbt works out the order

Real work is queries built on other queries. dbt reads every reference and builds them in order - that list you kept in your head, drawn for you.

That's dbt.
