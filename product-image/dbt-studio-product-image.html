The all-in-one IDE for data engineers: build dbt models, explore SQL, manage connections, run AI agent workflows, visualize lineage, create notebooks, and ship pipelines from one desktop app.

WHAT'S NEW AI + dbt

AI Agent for dbt

Ask the agent to create models, explain SQL, update YAML, run dbt commands, and reason over project context.

AI SQL editor

Monaco autocomplete, schema browser, saved queries, result export, and an agent that writes SQL, runs queries, inspects results, and updates the editor.

Visual dbt lineage

Trace models, sources, exposures, and downstream impact before you change production logic.

Electron desktop app

Local-first Electron workspace for projects, profiles, credentials, DuckDB, and files in one focused desktop loop.

Pipelines + FileFlow

Define .rosetta pipeline.yml flows, visualize steps, and run Terraform, Rosetta, dbt seed, run, and test locally or in cloud.

Cloud Explorer

Browse and preview S3, Azure Blob, GCS, R2, MinIO, Backblaze B2, Garage, RustFS, and compatible storage.

DuckLake UI

Browse tables, schemas, stats, files, partitions, and snapshots, then query DuckLake from the SQL Editor and Notebooks.

Multi-provider AI

Use OpenAI, Anthropic, Gemini, Ollama, LM Studio, and OpenAI-compatible providers with context.
