Pipeline Visualization

See Your Pipeline, Don't Just Write It

Rosetta turns your pipeline.yml into a live, interactive graph - read it, edit it, and run it.

Every job and step becomes a node. Zoom, pan, and fit the whole flow to screen - then edit it visually or drop straight into the YAML, and watch each step run live in the cloud.

Interactive Graph Visual + YAML Editing Live Run Status
The Graph

Your Pipeline, as a Graph

The control bar on the left handles zoom in and out, fit-to-view, and toggle interactivity - plus two ways to edit: the wand for Visual Edit, the pencil for raw YAML.

Visual Edit

Drag, Drop, Connect

Drag step types from the palette, wire the nodes in order, and hover any node for the pencil - click it to edit that step.

Edit a Step

Every Field Explained

Step name, plugin, command, working dir - and the job it belongs to. Every part of a step, in one panel.

Make a Change

Rename and Re-command

Rename the step to "Generate docs" and swap the command to "dbt docs generate" - then Apply.

Instant Update

The Graph Reacts

The node updates the moment you Apply. Hit Save to write the change back to pipeline.yml.

Saved

Written to the File

Back to the read-only view - your change is now part of pipeline.yml.

Commit

Stage, Commit, Sync

The cloud runs from your repo, so open the Git tab - stage the change, commit it, and sync to GitHub.

Run It

One Click to Run

Run Pipeline sits right beside pipeline.yml - or launch it from the Project dropdown. It kicks off in the cloud.

Live

Watch It Run

Steps light up as they go - Running, then success.

Success

Success Across the Board

Every step - Success - with the full cloud logs right inside the app. Next: the pencil, Edit pipeline.yml.

Edit pipeline.yml

Go Straight to the Code

The pencil opens pipeline.yml itself - your jobs and steps as plain YAML, fully editable.

Add a Step

Edit the YAML by Hand

Add a new dbt step directly - "Test staging models", running "dbt test --select staging" - in the build job.

Reflected

New Node, No Status Yet

The new node appears wired into the graph - with no status, because it hasn't run. Commit it, then run again.

Run Again

Watch It Run Again

The graph lights up step by step - now with a fourth node, the one we just added.

Done

All Four Success

Every step a success. See your pipeline, change it however you like, and run it - all from one place.
