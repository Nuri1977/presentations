Before The Project Opens

Seven steps, or a download

Same project, same local database. This is what each one wants from you first.

VS Code + dbt You do all of this
  1. Install Python
  2. Create a virtual environment, and reactivate it every session
  3. pip install dbt-postgres into it
  4. Write profiles.yml by hand — the project has no credentials
  5. Find it in ~/.dbt/, a hidden folder
  6. cd in, then dbt debug — or it says there is no project
  7. VS Code, Python extension, Power User, then its setup wizard
Seven steps, and none of them are the project.
Rosetta DBT Studio It does all of this
  1. Download and open it
  2. Point it at the project — folder or zip, it finds the root
  3. Fill in the connection form
  • Ships its own Python
  • Installs dbt and its adapters for you
  • No virtual environment to make or activate
Steps one to seven on the left happen for you on the right.
