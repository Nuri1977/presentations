Ask Mode

Ask Questions About Your Data

In Ask mode, the Agent explores your schema, reads your current query, and answers questions. "What tables are available?" "What does this column mean?" Read-only. Safe. Fast.

Code Mode

Generate, Execute, Inspect

Switch to Code mode and the Agent writes SQL, appends it to the editor, executes it, and reads the results — all autonomously. Multi-step tasks run end to end without stopping.

Safety First

You Approve Every Write Operation

Before running any INSERT, UPDATE, DELETE, or DDL statement, the Agent pauses and shows you exactly what it wants to execute. You click Allow or Deny. It never modifies your data without permission.

Closed Loop

Agent Reads the Results

After executing a query, the Agent reads the result pane — rows, columns, row count, duration. It uses that context to answer follow-up questions or continue multi-step tasks automatically.
