# Jaffle Shop Analytics — Phase 1 slides

Open `presentation-slides.html` in a browser and use the arrow keys or on-screen controls. The first six slides open with the finished Jaffle Shop report and follow its AI-assisted Analytics page through static export and browser verification. Five more slides explain the Markdown editor, live preview, AI assistance, query flow, components, and agent tools and context before the separate video. Slide 12 closes with links to download Rosetta DBT Studio and star the project on GitHub; place it after the Phase 2 video in the final edit. `voice-over-scipt.txt` contains narration for all twelve slides.

Slides 1–8 use screenshot backgrounds and short text cards on a fixed 1920 × 1080 canvas. The whole canvas scales to fit the window, preserving the image crop, card position, and text wrapping; extra space appears around it when the window has a different aspect ratio. Slides 9–11 retain the light striped background from `../iceberg-step-by-step/assets/linear-white-bg.svg`, copied into this deck's `assets/` directory. Screenshot filenames start with their slide number; slides 9 and 10 use native HTML visuals. The screenshot assets are copies of the images supplied for this presentation. Slide 11 displays only the Studio chat panel, hiding the desktop strip in the source screenshot.

The editable Analytics page is stored in Rosetta DBT Studio. The exported static site is saved in the dbt project at `rosetta_studio_analytics_demo/analytics-page/`. Its query results are captured at build time. The screenshots show demo measures; validate the revenue model before presenting those values as business results.

The closing slide uses the same light striped background and a fixed 1920 × 1080 canvas. A two-column grid keeps the logo, text, and links on the left and reserves the right for a speaking avatar added during video editing. Its Rosetta logo comes from `../iceberg-step-by-step/assets/icons/rosetta_logo.png`; its download and GitHub call to action follows the other presentation decks. Press End to jump to it.

Phase 2 is a separate live Studio video; no Phase 2 narration is included here.
