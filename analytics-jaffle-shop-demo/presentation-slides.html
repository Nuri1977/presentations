Demo · Architecture
dbt Project Structure

Four Layers, One Clean Project

Layer 1
Staging
One model per source table. Rename columns, cast types, deduplicate. No business logic.
stg_ordersstg_customersstg_payments
Layer 2
Intermediate
Complex joins that don't belong in staging and aren't final marts. Optional — keeps marts clean.
int_order_payments
Layer 3
Dimensions
Descriptive entities — who, what, where. Used by BI tools and fact tables.
dim_customers
Layer 4
Facts
Transactional data — measurable business activity. One row per event.
fct_ordersfct_payments

These mart tables become the data sources for our Analytics pages.
